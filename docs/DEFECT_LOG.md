# Engineering Postmortem and Defect Taxonomy

**Document Class:** Operational Verification (Categorized Root Causes, Shipped Fixes & Enforcing Guards)
**Baseline:** Synchronized to Contract **v33** (2026-11-16).

Every defect below occurred in this repository and shaped Hard Rules `1–30` in `AGENTS.md`. Application defects are **FIXED AND GUARDED IN `src/`** unless explicitly marked open; test-harness defects are identified separately below and do not imply a production UI change. For current open verification gates, see `docs/STATUS_AND_ROADMAP.md` §2–§3; for point-in-time commit transcripts, see `docs/audits/*.md`.

## 1. Security, Signing, and Consent Boundary Defects

| Defect | Root Cause | Shipped Fix & Mechanical Guard |
| --- | --- | --- |
| **Direct signing call bypassed review (`v32`, 2026-11-02)** | Under `v29–v31`, review enforcement was UI-only (`confirm.js` + UI literal scan); calling `tx.sendChecked` directly at the router built and signed with no prepared review. | `tx.confirmReview` mints a single-use 60s in-memory `consentToken` (`services/review/consent.js`) bound to `{ method, sha256(params), account, network }`; `api-router.js` rejects unreviewed calls with `REVIEW_REQUIRED` (`D-021`, `test/test-review-consent.mjs`). |
| **Auto-lock alarm skipped review discard (`2026-11-01`)** | Background inactivity alarm called `vault.lock()` directly instead of `walletService.lock()`, leaving prepared `tx_reviews` alive across auto-lock. | Centralized lock cleanup in `walletService.lock()` (clearing `tx_reviews` and `consentToken`s) + startup-while-locked cleanup; worker entry banned from importing `vault.lock` (`test/test-review-lifecycle.mjs`). |
| **Dashboard called `auth: 'signing'` `tx.autoCreateAccount` (`v29`)** | Background balance refresh fired `tx.autoCreateAccount` directly, bypassing review and failing silently whenever per-sign password re-auth was enabled. | Migrated `/dashboard` to `v12` `tx.registerAccount({ address })` (`auth: 'unlocked'`, exact vault-owned self-signer); static + dynamic UI signing-call scan in `test/test-tx-review.mjs` [14]. |
| **Hidden Domain batch queue signed without cards (`2026-10-30`)** | `routes/name.js` carried a `.hidden` batch queue loop calling `prepareReview` + `submitReviewedReview` without mounting `TxReviewCard`. | Deleted queue state, handler, controls, and `.name-queue-*` CSS (`test/test-tx-review.mjs` [17], `2026-10-30-review-lifecycle-audit.md`). |
| **`name.setRecord` shipped `unlocked` & threw on confirm (`v31`, 2026-10-29)** | Ungated write stayed `auth: 'unlocked'` outside `TRANSACTION_METHODS`, and `domainRecordRecheck` read non-existent `record.binding.accountAddress` (masked as `REVIEW_UNAVAILABLE`). | Promoted `name.setRecord` to `auth: 'signing'` in `TRANSACTION_METHODS`, fixed top-level `record.accountAddress` recheck, and added parameter-read enumeration (`test/test-name-records.mjs`, `test/test-signing-surface.mjs`). |
| **Faucet claim re-derived ambient account at submit (`2026-10-30`)** | `tx.claimFaucet` ignored reviewed account/network, risking cross-window account switch during confirm. | Bound `fromAddress` + `networkId` (`REVIEW_ACCOUNT_CHANGED` / `REVIEW_NETWORK_CHANGED`, `test/test-tx-review.mjs` [18]). |
| **Optional `signal` on `submitReviewedReview` (`2026-10-30`)** | Two of three routes omitted `AbortSignal`, allowing destroyed routes to finish signing after navigation. | `signal` is mandatory (`submitReviewedReview` throws before bridge call if absent; call-site scan in `test/test-tx-review.mjs` [17]). |
| **Vault KDF work factor lived only in code constant (`v1` envelope)** | Changing `PBKDF2_ITERATIONS` in code would silently brick existing vaults or weaken them without detection. | Vault ciphertexts persist `{ version: 1, kdf: { name, hash, iterations } }`, validated before derivation and fail-closed on future versions (`test/test-vault.mjs` [7b]). |
| **Legacy custom RPC & DOM/secret leaks (pre-rebuild)** | Custom RPC rows fell back to Betanet program IDs (`v7`); mnemonics leaked into `dataset.raw` / router history; ~20 `innerHTML` sinks existed; inputs lacked `spellcheck="false"`. | Background custom-RPC refusal + boot self-heal (`CUSTOM_NETWORK_DISABLED`, `CUSTOM_RPC_SUPPORTED = false`); `h()` DOM factory (`0` sinks in `check-layering.mjs`); `refs.js` opaque URLs + `findSecrets` sweep (`test/test-route-lifecycle.mjs`). |

## 2. Domain, Registrar, and Fee-Honesty Defects

| Defect | Root Cause | Shipped Fix & Mechanical Guard |
| --- | --- | --- |
| **Domain review printed `Network fee — none` (`H-1/H-3`, 2026-11-12)** | Registrar and `name.setRecord` builders copied CLI placeholder `fee: 0n` (`THRU_REGISTRAR_PROGRAM_FEE = 0`), and decoders hardcoded `'0'` instead of reading the network fee quote. | Unified `tx-units.networkFeeUnits` across registrar and name-service writes (`1n` on Betanet when funded, `"not confirmed"` when `baseFeeUnits == null`) + `assertFeeUnchanged` (`REVIEW_FEE_CHANGED`) at confirm (`D-022`, `test/test-tx-review-card.mjs` [5]). *(Minor cosmetic note `H-5`: `name.js` CTA balance hint checks `cost` rather than `cost + 1n`, caught cleanly by service validation before signing.)* |
| **3- and 4-character `.thru` names failed at write (`H-2`, 2026-11-12)** | `assertReviewContext` compared the reviewed tiered price (`100,000` / `10,000`) against flat `cfg.feePerYear` (`1,000`), always throwing `REVIEW_PRICE_CHANGED`. | Extracted `reviewPricePerYear(cfg, label)` (`pricePerYearFor` on tiered configs) across prepare, recheck, and write (`test/test-name-registrar.mjs` [7]). |
| **SDK `Pubkey` owner coerced to `"[object Object]"` (`2026-10-27`)** | `String(meta.owner)` failed on real `@thru/sdk` `Pubkey` instances while string-mocked tests passed. | Centralized `thruClient.getAccountOwnerAddress` using `Pubkey.from(...).toThruFmt()`, tested with real SDK `Pubkey` instances (`test/test-thru-client.mjs` [1]). |
| **Single primary-name key overwrote prior domains (`v29/v30`)** | `thru_primary_names` stored one alias per network; registering or unlinking lost tracked names. | Added versioned, revision-serialized `thru_registered_domains::<networkId>` inventory separate from primary selection (`test/test-name-primary.mjs`). |
| **Tri-state RPC outages misreported as `"does not exist"` (`v29/v31`)** | `!mintExists`, `accountExists: state.exists === true`, and boolean `domainExists`/`isOwner` collapsed `null` (RPC failure) into `false` (proven absent). | Enforced strict tri-state (`true` / `false` / `null`) across token, faucet, and domain-record facts/decoders (`test/test-tx-review.mjs` [2], [4], `test/test-name-records.mjs`). |
| **`APPEND_RECORD` labelled as `"Set"` & undeclared error codes (`v31`)** | Opcode 2 appends without replacing prior values; 13 `coded()` errors in `name-service.js` were missing from `manifest.js` `ERROR_CODES`. | Retitled `Add domain record` with append disclosure when key exists; `test/test-contract.mjs` scans services for undeclared error codes. |

## 3. Async State, Caching, and Protocol Serialization Defects

| Defect | Root Cause | Shipped Fix & Mechanical Guard |
| --- | --- | --- |
| **`BigInt` crashed Chrome JSON messaging (`Could not serialize message`)** | `faucetMaxPerClaim: 10_000n` crossed `chrome.runtime.sendMessage`, silently swallowed by legacy bootstrap `try/catch`. | `toPublicNetwork()` stringifies wire fields; `api-router.js` validates JSON serializability with field-path diagnostics (`test/test-api-router.mjs` [9]). |
| **Cross-network cache & slot collisions** | `knownTokenAccounts` and History block-time caches keyed by address or slot number alone leaked across network switches. | Cleared in-memory caches in `configureNetwork`; scoped storage via `scopedKey` (`9` `SCOPED_KEYS`) and block-time cache by `(networkId, rpcUrl, slot)` (`test/test-balance-network.mjs`, `test/test-history-block-time.mjs`). |
| **Concurrent storage read-modify-write races** | Parallel `pending.track()`, `review/store.js` prepares, or domain refreshes overwrote sibling records. | Per-network promise queues + schema v1 envelopes in `pending-tx-service.js`, `review/store.js`, `history-service.js`, and `primary-name-service.js` (`test/test-tx-review.mjs` [16]). |
| **SDK `0.4.1` zeroed default units & missing send expiry** | Omitting resource units caused `vmError -765/-767` on fresh activation/faucet claims; sends had no slot deadline. | Added `src/lib/tx-units.js` (`autoUnits` enforced on all 7 `buildAndSign` sites) and `SEND_EXPIRY_SLOTS = 1000` (`test/test-thru-client.mjs` [12]–[13]). |
| **Hand-rolled mint derivation lacked authority (`v8`)** | Custom encoder omitted mandatory mint authority and mismatched `@thru/programs/token` 1-byte tags. | Replaced with official `@thru/programs/token` builders/derivations and golden byte vectors (`test/test-thru-client.mjs` [10], [13]). |

## 4. UI Lifecycle, Layout, and Notification Defects

| Defect | Root Cause | Shipped Fix & Mechanical Guard |
| --- | --- | --- |
| **Empty black `toast()` bar (`2026-10-30`)** | Calling `toast('Transaction confirmed')` destructured a string into `{ title = '', message = '' }` and rendered empty full-width chrome. | `Rule 26`: `test/test-toast.mjs` bans bare-string calls in `src/`, `toast.js` normalizes strings internally and renders nothing on blank payloads (`2026-10-30-shared-platform-audit.md`). |
| **Domain printed one event three times (`2026-11-13`)** | Submit handler wrote the same verdict to `toast()`, `Banner()`, and `.name-status`. | `Rule 29` (`D-023`): one keyed `pending` `toast()` per submission event; `Banner` and field lines cleared before submit (`test/test-route-lifecycle.mjs`). |
| **`TxReviewCard` clipped addresses, folded blockers & bypassed `onChange`** | `.detail-address` ellipsized 46-char recipient addresses; `slice(0, 2)` hid a 3rd blocking warning; Domain built its Confirm button after `TxReviewCard` fired `onChange` in its constructor. | `.tx-review-address` (`word-break: break-all`), unfolded blocking warnings (`slice(0, 2)` applies to advisories only), and pre-declared Confirm button (`test/test-tx-review-card.mjs` [2], [6b]). |
| **`.tx-sheet` clipped bottom rows with no scrollbar (`Rule 14`)** | Flex children shrank (`flex-shrink: 1`) instead of overflowing `.tx-sheet`, invisible to the layout-free Node DOM shim. | `.tx-sheet > * { flex-shrink: 0 }` + `overscroll-behavior: contain` CSS guard in `test/test-route-lifecycle.mjs` + mandatory browser check (`scripts/preview-tx-sheet.html`). |
| **Side-panel mutual exclusion missed short windows / early boot** | `innerHeight > 600` misclassified `<600px` laptop panels, and listener attached after `await initTheme()`. | `?thru_panel=1` manifest query marker, synchronous pre-await listener registration, plus Chrome `sidePanel.close({ windowId })` (`test/test-route-lifecycle.mjs`). |
| **Detached listeners & focus-trap hidden-ancestor escape** | Fresh arrow functions in `removeEventListener`, discarded `PageHeader` in `reset.js`, and `isFocusable()` checking only self `.hidden`. | `disposer()` lifecycle contract, ancestor `.hidden` walk in `focus-trap.js`, and microtask `requestAnimationFrame` in `dom-shim.mjs` (`test/test-route-lifecycle.mjs`). |
| **Browser contrast oracle false greens (test harness, PR #31)** | Discarded text alpha and translucent ancestor layers could report `21:1` for independently measured `1.20:1` or `1.61:1` text. | `test/browser/address-contrast.mjs` composites all flat-color layers/group opacity before luminance, retains `4.5:1`, waits for the drawer's opening fade, and checks five independently specified ratio/threshold controls per theme. Production CSS is unchanged. |
| **Network chooser keyboard race (test harness, PR #31)** | Heading visibility did not mean the sheet's opening frame had assigned initial focus; that frame stole choice focus to Back before Enter. | `test/browser/network-chooser.mjs` waits for `.modal-overlay.open` and initial focus, then verifies exact switch requests, pending/error retirement, duplicate suppression, dismissal and one-message negative controls. |
| **Capture console exception hid application errors (test harness, PR #31)** | A substring exception for the native unload warning also swallowed an unrelated render failure containing the same words. | `test/browser/capture-ui.mjs` exact-matches the native warning, records it in each image's diagnostics, and retains unrelated/near-match application errors with negative controls. |
| **Concurrent rebuild deleted capture assets (test harness, PR #31)** | Reading mutable `dist/` for each browser request failed with `ENOENT` when another build removed `popup.html` mid-capture. | Capture snapshots the hashed bytes in memory and serves only that map. Missing-snapshot-asset refusal is controlled; final source/build hashes still reject a changed candidate. No generated files are manually edited. |
